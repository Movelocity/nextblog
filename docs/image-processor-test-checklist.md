# 图片处理器裁剪功能测试清单

## 🎯 测试目标

验证坐标系统重构后，裁剪功能是否准确、稳定、用户体验良好。

## ✅ 测试前准备

### 1. 准备测试图片

下载或创建以下测试图片：

- [ ] **网格图片**：带有明显网格线的图片（推荐：https://www.subjecttochange.com/resources/grid-paper-pdf）
  - 用于精确验证裁剪位置
  - 建议尺寸：2000x2000px

- [ ] **标记图片**：四个角有明显标记的图片
  - 用于验证边界裁剪
  - 建议尺寸：1500x1000px

- [ ] **超大图片**：高分辨率图片
  - 用于验证大图处理
  - 建议尺寸：4000x3000px 或更大

- [ ] **超宽图片**：横向宽图
  - 用于验证非正方形图片
  - 建议尺寸：3000x1000px

- [ ] **超高图片**：纵向高图
  - 用于验证非正方形图片
  - 建议尺寸：1000x3000px

### 2. 启动开发服务器

```bash
cd /Users/hollway/projects/nextblog/web
pnpm run dev
```

访问：http://localhost:3000/tools/image-processor

## 📋 测试用例

### 测试组 1：基础功能验证 ⭐⭐⭐

#### 用例 1.1：上传图片并进入裁剪模式
- [ ] 点击上传按钮，选择网格图片
- [ ] 图片正确显示在预览区域
- [ ] 点击"裁剪"按钮
- [ ] 裁剪模式正确启用
- [ ] 裁剪框默认覆盖整个图片（100%x100%）
- [ ] 裁剪框四周出现调整手柄

#### 用例 1.2：拖动裁剪框移动位置
- [ ] 鼠标悬停在裁剪框上，光标变为移动图标
- [ ] 点击并拖动裁剪框到图片左上角
- [ ] 裁剪框流畅跟随鼠标移动
- [ ] 释放鼠标后，裁剪框停留在正确位置
- [ ] 百分比显示正确更新

#### 用例 1.3：调整裁剪框尺寸
- [ ] 拖动右下角手柄放大裁剪框
- [ ] 拖动左上角手柄缩小裁剪框
- [ ] 拖动边缘手柄（上、下、左、右）单方向调整
- [ ] 所有调整都流畅且准确
- [ ] 尺寸显示实时更新

#### 用例 1.4：应用裁剪
- [ ] 选择图片上的特定网格区域（例如：左上角 3x3 个格子）
- [ ] 点击"应用裁剪"按钮
- [ ] 裁剪后的图片显示在预览区域
- [ ] **关键验证**：裁剪结果正好是选中的 3x3 格子区域
- [ ] 裁剪后的图片边缘清晰，没有多余或缺失的部分

**通过标准**：裁剪结果与选择区域完全一致，误差不超过 1 像素
